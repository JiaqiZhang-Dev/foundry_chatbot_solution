# Foundry Chatbot Solution

Reusable projects for building and operating Microsoft Foundry chatbot
solutions.

## Projects

| Project | Purpose |
| --- | --- |
| [`support-agent-template`](./support-agent-template/) | Executable template package that generates a Foundry support chatbot with optional Microsoft Teams integration and channel auto-reply |

Additional MCP servers and platform services can be added as sibling folders.
